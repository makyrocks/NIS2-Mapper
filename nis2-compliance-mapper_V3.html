  • Security Frameworks: NIST CSF 2.0 (Cybersecurity Framework), CIS Controls v8 (Implementation Guide)

☁️ SharePoint Integration Guide

🎯 Why SharePoint for NIS2 Compliance?

Benefits:

  • Centralized document management and version control
  • Collaboration across teams (Security, IT, Legal, Management)
  • Access control and audit trails
  • Integration with Microsoft 365 ecosystem
  • Automated workflows for evidence approval
  • Regulatory audit-ready documentation

📋 Setup Instructions

Option 1: SharePoint Document Library Structure

  1. Create SharePoint Site: "NIS2 Compliance Hub"
  2. Create Document Libraries:
    • 📁 Policies & Procedures
    • 📁 Risk Assessments
    • 📁 Incident Response Plans
    • 📁 Business Continuity Plans
    • 📁 Supply Chain Security
    • 📁 Training Materials
    • 📁 Audit Evidence
    • 📁 Vulnerability Reports
  3. Add Metadata Columns:
    • NIS2 Article (Choice: Art. 20, 21, 23, etc.)
    • Compliance Status (Choice: Compliant, Partial, Non-Compliant)
    • Review Date
    • Owner
    • Related Standard (ISO 27001, NIST, CIS, CSA)
  4. Configure Permissions: Security team, management, auditors
  5. Enable Versioning: Track all document changes
  6. Create Views: By NIS2 article, by status, by owner

Option 2: Power Apps Integration

  1. Create SharePoint lists for requirements tracking
  2. Build Power App canvas app for compliance tracking
  3. Connect to this HTML tool via Power Automate
  4. Automate alerts for non-compliance
  5. Generate compliance reports via Power BI

Option 3: Teams Integration

  1. Create Microsoft Teams channel: "NIS2 Compliance"
  2. Add SharePoint document libraries as tabs
  3. Pin this HTML tool as a website tab
  4. Use Planner for compliance tasks
  5. Regular Teams meetings for compliance reviews

📤 Export Data to SharePoint

To move your compliance data to SharePoint:

  1. Export your project as JSON (click "Export JSON" button above)
  2. Create a SharePoint list with columns matching your data
  3. Use Power Automate to import the JSON data
  4. Or manually upload evidence documents to document libraries
